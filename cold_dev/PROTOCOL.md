# Predeclared cold-station falsification protocol

Five outer station folds, stratified by static elevation >=1000m. Within each elevation stratum, sort station IDs and assign round-robin to folds0..4. This yields exactly two high-elevation targets per fold; all target stations are withheld together for every date. Primary comparison: pooled held-out-station diagnostic MAE, matched-drift graph minus exponential geographic/elevation covariance. Also report high-elevation MAE, p90 and each fold. No model variants beyond these two and a shared drift-only control. Go only if graph improves pooled MAE by >=5%, improves >=4/5 folds and does not worsen high-elevation MAE; otherwise no-go for this graph candidate, not all possible graphs.

Strict nested tuning: outer target temperature values from BOTH2021 and2022 are forbidden for fitting and parameter selection. For each outer fold, each of the other four station folds serves as inner held-out targets. Fit shared climatology on remaining stations'2021 temperatures; tune on inner target2022 even calendar weeks only. Pool inner errors and select one parameter set per method per outer fold. Refit shared climatology on all outer-training stations'2021 only. Evaluate outer targets only on2022 odd calendar weeks. No outer target response from either year enters tuning. This is station-level outer isolation, not merely masking2022 targets after using their2021 histories.

Climatology: ordinary linear regression on tensor products of [1, latitude, longitude, elevation] and [1, annual sine/cosine, semiannual sine/cosine]; static predictors centered/scaled using geometry only. Same seasonal trend for both priors. Same-day intercept/elevation residual drift estimated by each prior's generalized least squares on available non-target observations, using identical drift design and information. Drift-only OLS control uses the same design. GLS coefficients can differ by covariance; their formula and covariates are matched.

Exponential covariance grid: horizontal scale {90,220,500}km, elevation scale {750,2000}m, nugget {.001,.02,.1}. Graph grid: same horizontal/elevation scales, symmetric geographic6-NN weighted Laplacian, resolvent (I+strength L)^-1 with strength{1,10,100}, nugget .01. Each has18 candidates. Inner graph nodes exclude outer targets; final graph can include target static coordinates but no temperatures. Future extension/new-node geometry is allowed, historical target values are not.

Known limits: the preexisting36-station panel was originally chosen using2021 coverage, so availability selection is retrospective. No target temperature values are used to construct folds, fit models, or choose parameters; this is cold-station fitting within that existing panel, not a claim of prospectively sampled never-operated sensors. Same development year has been studied previously; this is a narrow falsification, not fresh confirmatory evidence.2023 remains sealed. Write this file before running results.
